# Kat Notes

A small todo app built with Preact and Firebase. Add tasks, edit them, delete them, and keep everything synced with Firestore. 🐱

## Features

- Add, edit, and delete todos
- Data stored in Firestore
- Optimistic updates so the UI feels instant
- Simple modal for adding tasks
- A bunch of random pages!

## Tech stack

- Preact
- Firebase (Firestore)
- Vite
